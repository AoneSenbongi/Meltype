# 括弧確定後の入力位置

Windows Native版の既存設定「カッコを打ったら中にカーソルを移動」を拡張する。

- 文章を含め、確定文字列の末尾が空の括弧ペアなら、その内側へ移動する。
- 自動で入った括弧内で文字列を確定したら、直後の閉じ括弧の外へ移動する。
- 対象の閉じ括弧はTSF範囲として保持し、同じ文書で直前に確定した場合だけ移動する。通常の括弧内編集には適用しない。
- 明示的な矢印・Home・End・Esc、フォーカス変更で追跡を解除する。既存の設定無効時の挙動を保持する。

実アプリの画面操作は行わず、隔離brokerと試験用TSF文書で検証する。実アプリでの利用感は別途確認が必要。
