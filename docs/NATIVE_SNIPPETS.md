# Windows Nativeの定型文

本家1.2.0の定型文登録・編集・削除・JSONの取り込みと書き出しを、既存のSnippetsFormとSnippetStoreを使って管理画面と通知領域から開く。保存先は本家と同じLOCALAPPDATA/Meltype/snippets.jsonとし、Googleのユーザー辞書や予測履歴とは分ける。既存のファイルを初期化しない。

自動モードで入力欄・行の先頭か空白の直後に「;名前」を打ち、SpaceまたはTabで登録文を展開する。複数行に対応し、展開直後のEscで「;名前」に戻す。未登録の名前は展開しない。登録変更は次の定型文入力から反映する。英語モードは直接入力を維持する。

独自TSFでは名前と展開結果を未確定文字として表示し、Enterまたは次の入力で確定する。本家のキー注入による後方削除は使わず、TSFの未確定範囲を置き換える。入力位置の直前の文字をTSFで確認し、コードの途中のセミコロン、パスワード欄、読み取り専用欄では展開しない。フォーカス移動や外部での確定では、既存の未確定文字の扱いに従う。

登録データを更新時のバックアップに含め、配布物には含めない。Microsoft／Googleの両変換先で同じ定型文を使う。

2026年10月11日、1.1.0-rc.4をこのPCへ適用した。本家画面の登録・編集・削除と保存、複数行・Esc復元・Tab展開・確定・取消を隔離ファイルで検証した。製品brokerのデータ保存先だけを試験用フォルダーへ置き換え、実際の名前付きパイプ通信からTSF文書への反映も通過した。入力アプリ固有の実操作は未確認。
