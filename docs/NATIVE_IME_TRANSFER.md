# 自分のPCへの導入

Windows 10／11 x64とGoogle日本語入力が必要です。

本家1.1.0対応の開発版ZIPでは予測候補を追加する。Tab／Shift+Tabで選び、Enterで確定、Escで選択解除する。SpaceはGoogleの文節変換に使う。学習停止中は予測履歴を追加しない。この変更は公開済み1.0.5のEXEには含まれない。

1. Releaseから Meltype-Native-Google-1.0.5-Setup.exe をダウンロードし、通常のダブルクリックで開く。
2. 保存先とデスクトップショートカットを確認し、セットアップを進める。必要な管理者確認を承認する。
3. 新規ならIMEを登録して起動し、導入済みなら辞書・設定・旧版のバックアップ後に更新する。
4. デスクトップまたはスタートメニューから管理画面を開く。

Windowsのアプリ一覧から削除できる。IME登録解除が失敗した場合はファイルを残す。Googleの辞書・学習履歴とバックアップは残る。旧ZIP版からの更新では旧導入先も保持する。

詳細は同梱のSECURITY.mdとソースのdocs/NATIVE_INSTALLER.mdを参照する。ランタイム・対応ソース・ライセンスを同梱し、個人の辞書・設定・履歴は含めない。

# 従来のZIP版を使う場合

対象はWindows 10／11の64ビット版。ARM版と32ビット版にはこのZIPを使わない。Google日本語入力は別途インストールする。開発環境やCodexは不要。

入力データの保存、権限、署名、報告先は[このForkのセキュリティ説明](https://github.com/AoneSenbongi/Meltype/blob/google-native-ime/SECURITY.md)を確認してください。新しい配布ZIPには`SECURITY.md`も同梱しています。

1. Google日本語入力をインストールし、一度日本語を入力して動作を確認する。
2. ZIPを`C:\MeltypeNative`など、移動しない場所へすべて展開する。ZIP内から直接起動しない。ダウンロードしたZIPに「ブロックの解除」がある場合は、展開前にプロパティで解除する。
3. `Meltype-Settings.exe`を開き、「インストール」を押す。普段使うWindowsアカウントで管理者確認を承認する。Googleの設定と学習データをバックアップしてからIMEを登録する。
4. 「起動」を押す。スタートメニューにも「Meltypeの管理画面」を追加する。

導入済みの場合は、新しいZIPを別の場所へ展開して`Meltype-Settings.exe`を開き、「この版に更新」を押す。GoogleとMeltypeの設定・履歴と更新前のファイルをバックアップしてから更新する。DLLが変わる更新では管理者確認が表示され、登録先も更新する。単語登録、辞書管理、Googleの設定、自動起動の切替も管理画面から操作できる。画面を閉じるとトレイに格納する。

日本語の句読点は全角の「，」「．」。ローマ字入力の区切りで`zh → ←`、`zj → ↓`、`zk → ↑`、`zl → →`を使える。Google本体でも同じ句読点を使う場合は、Google日本語入力のプロパティで句読点を「，．」に設定する。Googleへ新しい履歴を追加する場合は「学習する」を選ぶ。

インストール時にWindowsへのサインイン後の自動起動を設定する。起動時のコンソールは非表示。自動起動の有効・無効は管理画面から切り替える。設定変更前の自動起動情報は`backups`に保存する。通常のGoogle日本語入力へ戻す場合は「停止してGoogleに戻る」を押す。次回のサインインでもGoogleを使う場合は、自動起動も無効にする。削除は「インストール」の隣にある「アンインストール」から行う。確認画面を表示し、Googleの辞書・学習履歴とバックアップは残す。登録後にフォルダーを移動する場合は、先に登録を削除する。

Meltypeの常駐アイコンを右クリックすると「停止してGoogleに戻る」「単語登録」「辞書管理」を直接操作できる。Windows標準の「あ／A」のメニューは変更していない。

現在の1.0.4用ZIPは、句読点・疑問符でライブ変換がかなへ戻る問題と起動待ち時間の修正を含む。旧版からは管理画面の「この版に更新」で適用でき、個別の修正ZIPや辞書の移行は不要。

個人の辞書・学習履歴・設定はこのZIPに入っていない。導入先のPCにあるGoogleの辞書と履歴を使う。実際のアプリでのフォント・改行・候補配置は導入後に確認する。32ビットアプリとストアアプリは未検証。

1.0.3ではDLLなどの変換ファイルをProgram Filesの保護された版別フォルダーへ配置する。管理者確認が必要。管理画面・設定・バックアップは展開先に残るため、展開先も保持する。旧版からの更新でも辞書・学習履歴を維持する。更新後は入力アプリを開き直す。Windows検索欄へ反映されない場合はPCを再起動する。Windows 10の検索欄で入力できることは開発用PCで確認済み。Windows 11の検索欄と一般のストアアプリは未確認。

ソースは同梱の`corresponding-source.zip`と[GitHubのFork](https://github.com/AoneSenbongi/Meltype/tree/google-native-ime)で確認できる。対応するコミットは`SOURCE_VERSION.txt`に記載している。Meltypeのライセンスは`LICENSE`、同梱ランタイムのライセンスと第三者の通知は`runtime/LICENSE.txt`と`runtime/ThirdPartyNotices.txt`を参照。

1.0.4では、起動中は「起動」、停止中は「停止」を押せないようにした。自動起動はチェックで切り替える。エラーは日本語で説明し、詳しい技術情報は展開先のexperimental-buildに保存する。単語登録・辞書管理ボタンの青い強調表示も修正した。管理者処理の起動方法を見直したが、別PCで報告されたインストール失敗の解消は未確認。

Native開発版は本家v1.1.0の予測候補を取り込み、変換は公開1.0.5の判定・候補順とGoogle日本語入力を使う。Googleの辞書・履歴は初期化しない。文中のzh／zj／zk／zlはSpaceなしで矢印になる。先頭の[は未確定入力へ含め、後ろが日本語なら「、英語なら[として表示する。本家の選択範囲再変換はNative IMEでは未対応。
