# 本家Meltype 1.0.4への対応

公開対象は本家v1.0.4（55c8a29）の変更を取り込んだNative Google 1.0.5とする。日英判定、ローマ字変換、かなキー判定の共通コアを更新し、Google変換、TSFへの入力、句読点設定、学習停止、通信枠32、起動・停止ボタンと検索向け通信権限を維持する。

本家のQtアプリ向け貼り付け設定・処理は常駐版向けとしてソースに取り込む。Native IMEは引き続きTSFへ入力し、貼り付け経路を追加しない。本家のMac向け変更もソースに含めるが、配布物はWindows x64向けのみとする。

対応を検証する際は、本家の追加テストと共通・Windows全体、GoogleからTSFへの実文書変換、候補表示、句読点9組合せと学習停止、GUIの起動状態・更新判定、通信枠32、AppContainerからの通信と接続先拒否を確認する。新しいソースからインストーラーを再構築し、公開前に変更点・確認範囲を提示する。公開済み1.0.4と、このPCへ適用済みの本家1.0.3ベース版は、そのままの状態を維持する。
