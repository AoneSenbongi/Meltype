# 本家1.1.0の取り込み

## 対象

本家v1.1.0の共通コアと判定・辞書の改善を取り込む。Native Google版のTSF、Google日本語入力への接続、検索欄へのアクセス制限、通信枠32、管理画面は維持する。本家の別TSFサービスへ登録を切り替えない。

## 予測候補

入力中の読みや英単語から最大5件を、既存の白い候補一覧に表示する。通常の変換候補と同時には表示しない。Tabで次、Shift+Tabで前、Enterで選んだ予測を確定し、Escで選択を解除する。Spaceは従来どおりGoogleによる文節変換に使う。

日本語の予測は確定語句、ユーザー辞書、変換履歴を利用する。語句の履歴はPC内に保存する。学習停止中は履歴を追加せず、既存履歴の参照は続ける。句読点の個別設定を維持し、英語入力は半角のままとする。

## 検証と適用

本家のソース生成によるJSON処理に合わせ、Roslynによる構築には.NET SDKの`System.Text.Json.SourceGeneration.dll`が必要になる。`Build-Package.ps1`の`-JsonGenerator`、または環境変数`MELTYPE_JSON_GENERATOR`で指定する。配布物の実行時にはSDKは不要。

共通コアの回帰試験、予測の表示・選択・確定・取消、学習停止、Google連携とTSF候補表示の試験を行う。まずローカルで構築する。PCへの適用状態と公開状態は別に記録し、GitHub公開には内容の確認を取る。
