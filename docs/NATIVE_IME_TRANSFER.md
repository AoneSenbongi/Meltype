# Meltype Native 1.1.0の導入

Windows 10／11 x64とGoogle日本語入力が必要です。ARM版と32ビット版にはこの配布物を使わないでください。ランタイムを同梱しているので、開発環境やCodexは不要です。

## セットアップEXE

1. Meltype-Native-Google-1.1.0-Setup.exeを通常のダブルクリックで開きます。
2. 保存先とデスクトップショートカットを確認し、セットアップを進めてください。必要なWindowsの管理者確認を承認します。
3. 新規導入ではIMEを登録して起動します。更新では辞書・設定・履歴と旧版をバックアップしてから適用します。
4. デスクトップまたはスタートメニューの「Meltypeの管理画面」を開きます。

更新成功後は管理画面を開き直します。以後は「最新版を確認」で通常Releaseを確認し、更新を選ぶと取得・SHA-256照合・バックアップ・セットアップを実行します。入力アプリは新しいIMEを読み込むため開き直してください。詳細はdocs/NATIVE_RELEASE_UPDATE.mdを参照します。

Windowsのアプリ一覧から削除できます。IME登録解除に失敗した場合はファイルを残します。Googleの辞書・学習履歴とバックアップ、旧ZIPの導入先は保持します。

## 変換と入力モード

管理画面の「変換エンジン」でMicrosoft／Googleを選び、入力先へ戻ると反映されます。初期値はGoogleです。Microsoft側は本家の変換・候補取得・日英判別を使います。Microsoftの候補順はIME本体と一致するとは限らず、Microsoft辞書への学習書き込みは未対応です。単語登録と辞書管理はGoogle専用です。

「自動」では日本語と英語を判別し、「英語」では直接入力します。入力モードボタンのクリックまたは半角／全角キーで切り替え、それまでの未確定文字は確定します。候補は通常入力位置の下へ表示し、下に収まらない場合は上へ表示します。

本家1.2.1の共通コア・辞書・予測を取り込んでいます。予測候補はTab／Shift+Tabで選び、Enterで確定、Escで選択を解除します。Spaceは選んだエンジンの文節変換です。学習停止中は予測履歴を追加せず、既存履歴を使います。

句読点は管理画面から選べます。ローマ字入力の区切りではzh／zj／zk／zlで矢印を入力できます。自動起動は管理画面で切り替えます。管理画面を閉じるとトレイに格納します。本家の定型文管理画面、選択範囲再変換、Tab文節変換は独自TSFでは未対応です。

## ZIPから導入する場合

1. Google日本語入力をインストールし、一度入力して動作を確認してください。
2. ZIPをC:\MeltypeNativeなど移動しない場所へすべて展開します。ZIP内から直接起動しないでください。
3. Meltype-Settings.exeを開き、「インストール」を押して管理者確認を承認します。導入済みなら「この版に更新」を使います。
4. 「起動」を押します。登録後に展開先を移動する場合は、先に登録を削除してください。

## データと検証範囲

個人の辞書・設定・履歴は同梱していません。入力の処理はPC内で行い、入力文字をネットワークへ送信する処理は追加していません。バックアップには個人の入力情報が含まれるため公開しないでください。権限、ログ、署名、削除と報告先はSECURITY.mdを参照してください。

実アプリごとの入力動作、複数モニターの実操作、32ビットアプリは未確認です。Windows検索対応の検証範囲はdocs/NATIVE_SEARCH.mdに記載しています。

対応ソースはcorresponding-source.zip、対応コミットはSOURCE_VERSION.txtにあります。MeltypeのライセンスはLICENSE、同梱ランタイムはruntime/LICENSE.txtとruntime/ThirdPartyNotices.txtを参照してください。
