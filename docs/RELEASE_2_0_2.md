# Meltype Native Google 2.0.2-rc.2（公開候補）

本家Meltypeの非公式Forkです。PC適用済み2.0.2-rc.1に、学習と辞書・判定の改善を追加した公開候補です。公開はしていません。本家コアは1.3.0のままです。

## 2.0.1からの更新

### 文節区切りの移動と学習

- `VRChatter`のようにかなに読み直せない英語の文節も、Android版と同じくShift+矢印で区切りを動かせるようになりました。
- 打った元ローマ字の1音ずつで区切りが移動し、区切りを変えた後も元ローマ字を保持します。
- かなに読み直せる英語は従来どおり日本語の文節として扱います。最後の文節や、選んだ英語の次にかなに読めない英語が続く場合は、従来どおり何も変更しません。
- Shift+矢印で明示的に動かした文節区切りだけを`clause-boundaries.json`に記録し、次回同じ元ローマ字を打ったときに適用します。確定だけでは学習せず、Google／Mozc側の区切り学習も変更しません。学習データは「学習データを消す」「最近の学習を消す」とバックアップの対象に含めました。

### 本家1.6.0の辞書・判定の改善

- 本家1.6.0の分野辞書（JMED-DICTの医療、IDiMEの情報、SKKの駅名・固有名詞・人名、SudachiDictの一般語・固有名詞、e-Govの法令名）を候補に追加しました。いつもの候補・時刻の後ろ、絵文字の前に並べます。分野辞書は文節の区切り判定には使いません。
- 国名辞書は、このForkのGoogle判定で`ast`などの子音略入力と衝突したため取り込みませんでした。
- ユーザー辞書・同梱辞書の語が、変換エンジンの2次候補の後ろへ押しやられないようにしました。
- BackSpaceで打ちかけを消したとき、後ろのキーを見て決めた単位（ffのっ、nkのん）を作り直します。`nk`＋BackSpace＋`a`は「んあ」ではなく「な」になります。

## 2.0.1から引き継いだ機能

- 文章末尾の空の括弧を確定すると内側へ移動し、括弧内の文章を確定すると外側へ移動します。
- Google日本語入力の辞書と学習履歴を使う変換、Google変換での文節編集に対応しています。
- 文脈に応じた候補選択でzenzモデルとCPUランタイムを同梱します。zenzはAVX2対応CPUで利用でき、非対応CPUでは通常変換を使用します。

## 導入

公開候補のため、現時点では配布しません。公開時に添付するSetup.exeを実行してください。Windows 10／11 x64向けで、Google日本語入力が別途必要です。更新後は入力先のアプリを開き直してください。
