## 操作と設定

対象は計算候補、Escの段階取消と選択文節取消、Enterの表示どおり確定、F9/F10初回操作、選択文節F6-F10、半角空白、括弧・スラッシュの表記、括弧内移動、Control割当、英字優先入力。独自Native設定画面に入力設定ダイアログを設け、保存した項目をbrokerのCompositionOptionsへ接続する。

計算候補は有効にする。Esc・Enter・括弧などの操作変更は設定から選択できるが、利用者が確定していない変更は既定で無効。選択文節のF6-F10は現行動作を維持して有効。Shift+Spaceの全角、英語直接入力維持、打鍵補助非表示、既存句読点・学習停止は維持する。子音略入力と文脈別の日英学習は無効・今回の設定対象外。GitHub・クリップボード候補・打鍵記録は有効化しない。

## 検出した不具合と修正

本家のライブ変換の長さ判定では、数字を数えないため0.75baiなどの短い単位がかなのままになる。既存の実TSF回帰と追加した単体試験で検出し、数字付き入力は従来の長さ判定を維持した。記号だけで短いかなを漢字にしない本家の修正は保持する。

括弧内カーソル移動は、本家の合成Leftを独自brokerが物理Enterの再送と区別できなかった。rc.7のDLLを隔離配置した実TSF試験で失敗を確認し、左移動だけの通信アクションを追加した。確定後にTSFの選択位置を1文字戻し、周囲の文字と変換終了を保ち、Enterを再送しない。Control割当も実TSFのCtrl+TからF7への変換で確認した。
