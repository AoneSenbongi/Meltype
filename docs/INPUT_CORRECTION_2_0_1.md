# 2.0.1-rc.1 入力操作の修正

2026年10月15日、利用者はUSキーボードのAlt+`で英語へ切り替えた後、メールアドレスや打鍵文字列をそのまま入力したいと指定した。このPCのDirectModeAutoDetectをfalseへ変更する。自動モードの日英混在判定は維持する。明示的に自動復帰を有効にする設定は残す。

文節選択中のF6〜F10は選択文節だけへ適用し、他文節と未確定状態を保持する。F6はひらがな、F7/F8はカタカナ、F9/F10は打鍵英字とし、同じ英字キーの連打で大文字、先頭大文字へ切り替える。変換前は従来どおり入力全体へ適用する。左右で対象文節、Shift+左右で境界を変更する。操作案内にF6/F10を表示する。

修正前の再現試験では、F6が「単位を取る」全体を「たんいをとる」へ、F10が全体をtanniwotoruへ変えた。修正後は「単位をとる」「単位をtoru」を要求する。PC適用では版番号を2.0.1-rc.1へ更新し、標準更新とバックアップを使う。公開はしない。

## 検証・適用結果

全体回帰524/524、標準パッケージ一式、実TSF文書で選択文節だけのF6/F10と確定に通過した。2026年10月15日22:19JSTに標準更新が成功し、このPCへ2.0.1-rc.1を適用。登録と7ファイルのハッシュ、導入brokerでの英語直接入力と文節F6/F10、broker/modelのプロセスとhealthを確認した。設定DirectModeAutoDetect=falseを維持。物理USキーボードでのAlt+バッククォートは利用者の手入力確認が残る。
