Meltype Native 2.0.0

Google日本語入力の辞書を使い、変換の区切りを自分で直せる日英混在IME。

本家Meltype 1.3.0の日英自動判別・共通変換処理・辞書を基にした非公式Forkです。
Google日本語入力との連携、独自のWindows入力処理と管理画面を追加しています。
Googleや本家作者の公式配布版ではありません。

対応OS：Windows 10／11 x64
Mac・Linux：未対応

ダウンロード
https://github.com/AoneSenbongi/Meltype/releases/tag/native-google-2.0.0

主な機能

1. 変換の区切りを変えて、欲しい候補を選ぶ

   変換結果が違っていたら、打ち直す前に文節の区切りを直せます。
   Spaceで変換し、左右キーで文節を選び、Shift＋左右で読みの範囲を縮めたり広げたりします。
   変更した範囲でGoogleの変換候補を取得し直します。

   たとえば「にだい」が「に｜だい」に分かれて「荷台」が見つからないときは、
   範囲を「にだい」に広げて候補を選べます。

   意図せず英語と判定された部分も、Shift＋左右で修正できます。
   日本語として読める入力であれば、その読みで文節を作り直して変換します。
   全文が英字表示になった場合も操作を始められます。
   URLや日本語として読めない英字は無理にかなへ変えません。

   文節編集自体は本家にもあります。このForkでは、独自Google連携での区切り変更、
   変更後の候補取得、英語誤判定からの修正を一続きで行えます。

   操作の図
   docs/images/native-2-boundary.svg

2. zenzが誤字を検出し、修正して変換する

   前後の文脈から、変換エンジンが用意した候補の表記をローカルAIで選び直します。
   ローマ字の打ち間違いで英字が残った入力も、元の表示と修正候補を比較して変換します。
   例：onegaishimsu → お願いします、sumimasne → すみません。
   誤入力を繰り返して英語扱いになった場合も再評価します。すべての誤字が対象ではありません。
   モデルはSetup.exeで一緒にインストールされ、別途ダウンロードや手動設定は不要です。
   PC内のCPUで処理し、クラウドAIやAPIキーは使いません。
   詳しい動作・CPU条件・制限は別紙を参照してください。
   docs/ZENZ.txt

3. Googleの辞書・学習履歴を引き継いで使う

   インストール済みのGoogle日本語入力へ変換を依頼します。
   普段使っているユーザー辞書と学習履歴を利用でき、単語登録・辞書管理もGoogleの画面から行えます。
   学習を有効にした場合は、確定結果の一致を確認してGoogleへ学習させます。
   Google本体やシステム辞書は改造・同梱しません。

   管理画面でMicrosoft IMEにも切り替えられます。初期値はGoogleです。
   Microsoftの候補順はIME本体と一致するとは限らず、Microsoft辞書への学習書き込みは未対応です。

4. 管理画面で設定・辞書・更新を操作する

   句読点、学習、自動起動、Googleの辞書、定型文を管理できます。
   入力操作の設定も同じ画面に直接配置しています。
   設定の変更後は「入力設定を保存」、句読点は「句読点を保存」を押してください。
   右側はスクロールできます。管理画面を閉じると通知領域へ格納します。

   管理画面の実画像
   docs/images/native-2-settings.png

本家から引き継いでいる機能

・日英自動判別、共通辞書
・予測変換：Tab／Shift＋Tabで選択、Enterで確定
・定型文：登録・編集・削除・JSON入出力、;名前をSpace／Tabで展開
・計算候補：数式をSpaceで変換して結果を選択
・Escの段階取消、選択文節の取消
・Enterの表示どおり確定、F9／F10の初回操作、選択文節へのF6〜F10
・空白、括弧、スラッシュ、角括弧の表記設定
・括弧だけの確定後に内側へ移動する設定
・英字優先入力、Controlキーへの操作割り当て
・本家1.3.0の「雪の結晶＋M」アイコン

これらを独自のWindows入力処理へ接続しています。
括弧内移動は、確定後にカーソルが外へ戻るNative側の不具合も修正しました。
本家の基準版は1.3.0、このForkの配布版は2.0.0です。

このForkで追加・変更した部分

・Googleとの接続、既存辞書・履歴の利用、確定結果の学習
・Google変換の区切り変更後の候補取得と、英語誤判定からの修正
・Google／Microsoftの選択
・独自TSFによる、元の入力欄への未確定表示と候補表示
・ローカルzenzによる文脈に応じた候補選択、ローマ字誤字の検出・修正変換、モデルのSetup同梱
・独自管理画面、入力設定の直接配置、EXE導入、更新確認、更新前バックアップ

本家の機能のうち、このNative版で未対応のもの

・子音の略入力
・前の文脈ごとに分ける日英学習
・英字の社名・サービス名の予測
・GitHub Issue／PRのタイトル候補
・クリップボードの内容を変換候補へ追加
・打鍵間隔の実験記録

本家の設定ファイルをコピーしても、これらは有効になりません。
コードエディター向け判別を含め、本家の機能すべてに対応したものではありません。

インストール

1. Google日本語入力をインストールし、日本語を入力して動作を確認します。
2. ReleaseからMeltype-Native-Google-2.0.0-Setup.exeを取得して開きます。
3. 保存先とショートカットを確認し、必要なWindowsの管理者確認を承認します。
4. スタートメニューかデスクトップの「Meltypeの管理画面」を開きます。
   更新した場合は、入力に使うアプリも開き直してください。

ランタイムとzenzモデルは同梱しています。別途.NETや開発環境を入れる必要はありません。
ARM用・32ビット用パッケージは提供していません。
従来のMeltype常駐版が動いている場合は先に終了してください。

基本操作

・Space：変換候補を選ぶ
・Enter：確定
・変換中の左右：文節を選ぶ
・変換中のShift＋左右：文節の範囲を変更
・Tab／Shift＋Tab：予測候補を選ぶ
・半角／全角キー、または入力モードボタン：「自動／英語」を切り替え
・文字を選択して変換キー：再変換。Enterで確定、Escで元に戻す
・行頭か空白の直後で;名前をSpace／Tab：登録済み定型文を展開
・計算候補を有効にして1+2*3をSpace：7や1+2*3=7を候補から選択
・括弧内移動を有効にして()をEnter：内側へ移動。全角設定ONなら（ ）になる

英語直接入力中のShift＋左右は、入力先の範囲選択として扱います。
Google選択時は、日本語の読みが4文字以上になるとSpaceの前にも表示を更新します。
表示が変わっただけで文字を確定することはありません。

保存されるデータとプライバシー

入力の判別・変換・モデル推論はPC内で処理します。
このForkに入力文字を外部サーバーへ送る処理は追加していません。
更新確認と配布物の取得ではGitHubへ接続します。Google本体の通信設定は別です。

Googleの辞書・履歴は導入先の既存データを使います。
Meltypeの設定・予測履歴・定型文もPC内へ保存します。
定型文は%LOCALAPPDATA%\Meltype\snippets.jsonです。
学習停止は新しい履歴の追加を止める操作で、既存の履歴は利用します。
Googleを直接使う場合の学習設定は変更しません。
更新前のバックアップには個人情報が含まれるため、そのまま公開しないでください。
配布物に開発者個人の設定・辞書・入力履歴は含めません。

更新・停止・削除

1. 更新：管理画面の「最新版を確認」から更新するか、新しいSetupを開きます。
2. 停止：「停止してGoogleに戻る」で通常のGoogleへ戻します。
   入力先と合わない場合はWin＋Spaceでも切り替えられます。
3. 削除：Windowsのアプリ一覧からアンインストールします。
   Googleの辞書・学習履歴とバックアップは残します。
   登録解除に失敗した場合はファイルを残して中止します。

無操作で更新する方式ではありません。更新後は入力アプリを再起動してください。

検証と制限

入力操作・変換・誤字補正の自動試験、実モデルと入力サービス経由の確定試験を実施しています。
括弧内移動はWindows EDITで再現・修正を確認し、利用者の実操作でも成功報告を受領しました。
モデルの別フォルダー配置・推論・終了・移動後起動と、同梱元からのTSF連携も検証しています。
モデル同梱の前回Setupは、利用者から別PCでの導入成功の報告を受けています。
今回追加した誤字補正を含むSetupの別PCでの実入力は未確認です。

32ビットアプリ、一般のストアアプリ、複数モニターは網羅試験していません。
Google連携は非公式IPCのため、Googleの更新で接続できなくなる可能性があります。
不具合の報告には、版番号・アプリ名・入力操作・期待した結果・実際の結果を添えてください。
ログやバックアップを添付する前に個人情報を確認してください。
