# Meltype Native 1.1.0

WindowsのMeltype IMEで、変換先をMicrosoft IMEとGoogle日本語入力から選べるようになりました。本家Meltype 1.2.1の共通コア・辞書・予測を取り込んでいます。

## 変更点

- 管理画面の「変換エンジン」でMicrosoft／Googleを選択できます。入力先へ戻ると反映され、初期値はGoogleです。Microsoft側は本家の変換・候補取得・日英判別を使います。
- IME一覧・管理画面・通知領域に本家由来のMeltypeアイコンを表示します。
- 小さいIMEアイコンでも見えるよう、本家ロゴの中央を大きく表示します。
- 本家の定型文登録・編集・削除、JSONの取り込み・書き出しを利用できます。自動モードで行の先頭か空白の直後に「;名前」を入力し、Space／Tabで展開、直後のEscで元に戻せます。複数行にも対応します。
- 入力モードの表示を「自動／英語」に統一しました。クリックまたは半角／全角キーで切り替え、切り替え前の未確定文字は確定します。
- 画面下端で候補が見切れる問題を修正しました。下に収まらない場合は入力位置の上へ表示し、候補数が変わる場合も配置を再計算します。
- 予測候補はTab／Shift+Tabで選び、Enterで確定、Escで選択解除できます。Google連携、Windows検索対応、句読点設定、学習停止も保持しています。

## 導入・更新

Windows 10／11 x64用です。Google日本語入力は別途インストールしてください。

1. 添付のMeltype-Native-Google-1.1.0-Setup.exeを開きます。
2. 保存先とショートカットを確認し、必要なWindowsの管理者確認を承認してください。
3. 更新後は入力アプリを開き直します。管理画面の「最新版を確認」からも更新できます。

更新時は辞書・設定・履歴をバックアップし、Googleの既存データを保持します。EXEにはランタイム、対応ソース、ライセンスを同梱し、個人の辞書・設定・履歴は含めていません。SHA-256は添付の.sha256ファイルで確認できます。

## 検証

Native関連17件、Google関連13件、Microsoftの変換・候補取得2件を確認しました。両エンジンから実TSF文書への未確定文字の更新・確定・取消、予測選択、入力モード、画面端の候補配置、番号一致、設定保存、更新と失敗時の復旧も検証しています。変換試験は学習無効で実施しました。

確認用1.1.0-rc.4を開発用PCへ適用し、配置ファイルの一致、サービス起動、拡大した本家アイコンとモード切り替えをDLLの試験で確認しました。本家の定型文画面による登録・編集・削除と保存、実brokerの通信からTSF文書への複数行展開・復元・確定・取消も検証しています。修正後の正式版EXE、実アプリごとの入力動作、複数モニターの実操作、32ビットアプリは未確認です。

## 制限

Microsoftの候補順はMicrosoft IME本体と一致するとは限りません。Microsoft IMEの辞書への学習書き込みは未対応です。Googleの単語登録・辞書管理はGoogle専用です。選択範囲再変換とTab文節変換は独自TSFでは未対応です。

配布EXEはコード署名をしていません。Google連携は非公式IPCを使うため、Googleの更新によって接続できなくなる場合があります。
