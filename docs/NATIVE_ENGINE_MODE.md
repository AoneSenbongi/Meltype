# Windowsの変換エンジンと入力モード

管理画面でMicrosoft IMEとGoogle日本語入力を選ぶ。既存利用者の初期値はGoogleとし、日英自動判別、ライブ変換、句読点設定、予測を維持する。選択はinput-preferences.jsonのConversionEngineへ保存する。入力先へ戻った後の新しい接続から反映し、未確定文字を途中で別のエンジンへ渡さない。

Microsoftは本家のMsImeKanjiConverter、WinRtCandidates、現在の日英判別を使う。COMの生成・呼び出し・解放は接続ごとの専用STAスレッドで行う。Googleへ変換や学習を送らない。Googleでは従来の判別を維持する。Microsoftの候補APIはMicrosoft IME本体の候補順と一致するとは限らず、Microsoft IMEの辞書への学習書き込みは提供しない。Meltypeの予測履歴は既存の学習設定に従う。

IME一覧と入力モードボタンのアイコンは、本家のdocs/images/logo.pngにある水色とピンクのロゴを使う。小さい表示でも見えるよう中央の文字を大きく切り抜き、透明背景のICOへ変換してDLLへ組み込む。入力モードの文字表示は「自動」「英語」とし、クリックと半角／全角キーで同じ状態を切り替える。自動では日英判別を行い、英語ではキーを入力先へ直接渡す。切り替え前の未確定文字は確定する。管理画面と通知領域も同じロゴを使う。

WindowsのKEYBOARD_OPENCLOSE区画を有効化時に自動モードへ設定し、切り替え時も同期する。Windows側から区画が変更された場合はMeltypeのモードへ反映する。INPUTMODECOMPARTMENTカテゴリを登録する。パスワード欄や読み取り専用欄の入力保護は維持する。入力できない欄でのWindowsの無効表示は強制的に隠さない。

英語モードで通常のキー通知が停止しても半角／全角で自動へ戻れるよう、VK_KANJIをTSFの保持キーとして登録する。保持キーでも入力先の保護判定を行う。

正式版番号は1.1.0とする。確認用の1.1.0-rc.1と修正前の1.1.0は開発用PCへ適用済み。モード修正の先行適用に1.1.0-rc.2を使い、アイコン拡大と定型文対応は1.1.0-rc.3とし、修正後の正式版1.1.0を初めてGitHubへ公開する。このPCへの適用は承認済み。外部公開は最新の利用者指定AGENTS.mdに従い、今回の内容を提示して承認を受ける。

変換候補は通常、入力位置の下へ表示する。入力位置が属するモニターの作業領域へ収まらない場合は、入力位置の上へ表示する。タスクバーを含めて画面からはみ出さないよう上下左右の位置を調整し、候補数が変わった場合も配置を再計算する。表示によって入力先のフォーカスを変更しない。
