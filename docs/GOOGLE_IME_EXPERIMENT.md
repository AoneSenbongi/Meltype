# Google日本語入力との試験的な連携

変換ボックスは入力中の背景を透明にし、変換候補を選ぶときだけ白い背景に濃い文字を表示する。外枠は表示しない。文字の大きさ、余白、候補一覧、操作案内は維持する。透明な状態の文字は細い暗色の縁取りで白い入力欄でも読めるようにする。候補の選択は下線と左の短い目印で示す。候補の意味を表示する別のポップアップも白い背景に濃い文字を表示する。変換と学習の処理は変更しない。

通常の連携処理はGoogleの設定を変更せず、シークレット設定や学習停止設定に従う。Googleにも履歴を追加する場合は、Google日本語入力のプロパティで「学習する」を選ぶ。設定変更前にバックアップを取る。

常駐試験は同梱済みのPowerShellランタイムで起動する。試験用ホストでは自動起動登録・更新・復元・アンインストールのメニューを非表示にし、起動と終了はワークスペースのスクリプトで行う。

Windows版の設定「変換エンジン」に「Google日本語入力（試験版）」を追加する。Meltypeの日英判定と変換画面を維持し、日本語の読みと変換候補をインストール済みのGoogle日本語入力の変換サーバーとやり取りする。

Googleが公開しているMozcの通信形式を参考にした非公式の連携であり、製品版Google日本語入力の将来の互換性は保証されない。Google日本語入力をインストールし、一度通常の入力を行って変換サーバーを起動してから選択する。連携側からGoogleのプロセスを起動・停止・再起動しない。

常駐版では専用の通常セッションを使用し、Googleの既存の学習履歴を使った変換と新たな学習を行う。入力中の変換は確定せず、ユーザーがMeltypeで確定した日本語だけをGoogleにも確定する。学習時に同じ読みを変換し直し、文節の区切りと各候補がユーザーの確定内容に一致することを確認する。一致しない文節やGoogleに存在しない候補は学習しない。Googleの全体設定・辞書・学習ファイルは直接変更しない。Google自身のシークレット設定が有効な場合は、その設定に従う。

実接続の読み取り試験は専用のシークレットセッションを使い、学習を追加しない。学習を追加する試験は明示的な別の試験コマンドで行う。バックアップは隠し属性のファイルも含めて取得し、ハッシュを照合する。

接続先は稼働中のGoogleIMEJaConverter.exeの名前付きパイプに限る。複数の候補がある場合は接続しない。接続と読み書きに時間制限を設ける。接続に失敗した場合、別のエンジンへの自動切替はせず、Meltypeが通常備えるかな等の候補を残す。設定から他の変換エンジンに戻せる。

Googleの変換結果では、全角の「？」等が読みの中で半角になる場合がある。記号の幅だけが変わった結果は受け取り、各文節の読みを元の入力へ対応させる。記号だけの文節と候補は入力時の幅に戻す。かな・英字・数字の不一致や読みの欠落は従来どおり拒否する。これによりSpace前の句読点や疑問符でライブ変換がかなへ戻ることを防ぐ。学習の確定内容の一致確認は緩めない。

検証では、単語と複数文節の変換、各文節の候補取得、日英混在入力、切断時の応答、試験セッションの破棄、確定内容の一致確認と学習後の候補順位を確認した。常駐起動も確認したが、Computer Useの画面取得に失敗したため、実アプリでのキー入力は未検証。Windowsへのサインイン時の自動起動は今回は登録しない。
