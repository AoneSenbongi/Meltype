# Windows Native版への本家入力機能の移植

2026年10月14日の利用者の依頼により、直接入力中のローマ字判定、選択範囲の再変換、Tabでの文節変換を独自TSFへ接続する。Androidは対象外。作業先はTools/1.1.1-source。候補番号は1.1.2-rc.2とし、既存rc.1のPC適用と公開候補の記録は保持する。

直接入力では本家のDirectModeAutoDetect設定とScoreEngineを使う。判定中も英字を即時入力し、日本語へ戻す際は、この接続が直前に入力した英字との一致をTSFの読み書きセッション内で確認して置き換える。選択範囲やキャレット位置が変わった場合は判定を破棄する。英語判定後は語の区切りまで直接入力を維持する。パスワード・PIN・私有・読み取り専用・IME無効欄は処理しない。

再変換は自動モードで選択範囲を作り、変換キーを押して開始する。かなは正規化し、漢字は本家と同じMicrosoft IMEの逆変換で読みを取得する。ローマ字の文章は共通コアの再変換を使う。読みが取得できない場合は文字を変更しない。未確定表示は選択範囲内に置き、Escは元の文字を復元する。Enterは現在の候補を確定する。Google/Microsoftの変換先を保持する。

Native管理画面に「英語モードでもローマ字を検知」と「Tabで変換」のスイッチを置く。本家と同名のDirectModeAutoDetect・TabConversionをinput-preferences.jsonに保存する。初期値は本家と同じtrue。句読点・学習・変換先の保存時も両設定を保持する。Tabは予測候補や定型文がある場合に既存の選択・展開を優先する。Tabで始めた変換では、Tabで次の候補、Shift+Tabで前の候補を選ぶ。文節移動は←→を使う。空の入力欄ではフォーカス移動を妨げない。

実装前に隔離データと実TSF文書による試験を追加し、旧実装の失敗を確認する。製品の学習・個人辞書は試験に使わない。実装後はGoogle/Microsoft、予測、定型文、入力モード、保護欄と配布パッケージを検証する。PC適用と外部公開は今回の実装・検証完了とは分けて報告する。
