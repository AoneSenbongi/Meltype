# Meltype Native Google 1.0.3

Windows 10の検索欄でも、Google日本語入力を使ったMeltypeの変換を利用できるようにしました。既存のGoogle辞書・学習履歴を使い、日英自動判別とライブ変換を行います。本家Meltype 1.0.1を基にしたForkの更新です。

## 変更点

- Windows 10検索向けのIME登録・保護されたDLL配置・通信を追加しました。通信許可の追加先はWindows 10の検索パッケージに限定し、双方の接続先確認を維持しています。
- Spaceで候補を選ぶと、白い候補一覧の選択表示が更新されるように修正しました。
- 適用済みの配布内容では「この版に更新」を押せないようにしました。
- 更新の取消や失敗時に、旧登録・設定・自動起動・サービスを復旧する処理を追加しました。

## 導入・更新

Google日本語入力が必要です。ZIPをすべて展開し、`Meltype-Settings.exe`を開いて、新規導入は「インストール」、旧版からは「この版に更新」を押してください。管理者確認が表示されます。辞書・設定・旧版をバックアップしてから更新します。

変換ファイルはProgram Filesへ配置します。管理画面・設定・バックアップは展開先に残るため、展開先も保持してください。Google本体・辞書・学習履歴は変更せず引き継ぎます。更新後は入力アプリを開き直してください。Windows検索欄へ反映されない場合はPCを再起動してください。

## 検証結果と制限

開発用のWindows 10 PCへ適用し、利用者が検索欄で入力できることを確認しました。通常のGoogle・TSF変換、候補表示、更新判定、取消・起動失敗時の復旧試験も通過しました。隔離したAppContainerでは、ライブ変換・候補取得・日本語確定と、不正な接続先の拒否を確認しています。

Windows 11の検索欄、一般のストアアプリ、32ビット・ARM64・署名必須のアプリは未対応または未確認です。全キー操作・全入力先・全端末での動作を保証するものではありません。動作しない入力先ではWin＋SpaceでGoogle日本語入力へ切り替えてください。Googleとの非公式IPCを使うため、Googleの更新で動作に影響する可能性があります。

入力文字をネットワークへ送る処理は追加していません。コード署名と第三者のセキュリティ監査はありません。詳しい権限・保存場所・制限は[SECURITY.md](https://github.com/AoneSenbongi/Meltype/blob/google-native-ime/SECURITY.md)を確認してください。

AssetsのZIPにはランタイム・対応ソース・ライセンス通知を同梱します。個人の辞書・設定・学習履歴・ログは含めません。SHA-256は添付の`.sha256`ファイルで確認できます。
