# Windowsインストーラー

1.0.6はWindows 10/11 x64向けのEXEインストーラーを主な配布物とする。Google日本語入力は別途必要。配布ランタイム、対応ソース、ライセンスとセキュリティ説明を含める。

配布版番号は管理画面のタイトル、IMEの登録状態、セットアップの表示・ファイル名・Windowsのアプリ一覧で一致させる。本家のコア版番号とは区別する。このPCへ先行適用する場合も表示番号を変更し、公開版と同じ番号で内容だけを差し替えない。公開前の候補は予定版番号に候補番号を付け、例として1.0.7-rc.1とする。通常Releaseへ移す際は正式な番号へ揃える。Test-NativeVersion.ps1で関連箇所の一致を確認してから配布・先行適用する。

セットアップは通常のWindowsユーザー権限で起動する。管理画面などを利用者ごとの固定フォルダーへ配置し、既存のインストール・更新処理を呼び出す。IME登録と保護されたDLLの配置のみ管理者確認を求める。別のWindowsアカウントの資格情報で承認した場合は処理を中止する。

新規導入ではIMEを登録して起動する。導入済みなら既存の更新処理を使い、Googleの辞書・学習履歴と旧版バックアップを保持する。旧ZIP版の導入先は既存更新処理に従い維持する。セットアップ後も旧ZIP版の導入先を削除しない。新たな配布ファイルの配置先と稼働中IMEの管理先が異なる場合は両方を保持する。

デスクトップとスタートメニューへ管理画面のショートカットを作成する。デスクトップのリンクは既定で作成し、セットアップで解除可能にする。日本語やOneDriveのデスクトップはWindowsの既知のフォルダーAPIを使う。

Windowsのアプリ一覧から削除できるようにする。先にIME登録、自動起動、ショートカットを削除し、成功後にセットアップが配置したファイルのみを削除する。管理者確認の取消やIME登録解除の失敗時はファイル削除を行わない。Googleの辞書・学習履歴、バックアップは保持する。既存ZIP版のフォルダーはセットアップから削除しない。

セットアップと更新で入力サービスの実行を管理者権限へ引き上げない。起動・更新失敗は日本語で案内し、技術情報をローカルログへ保存する。署名なしと動作確認範囲をReleaseに明記する。公開はEXEと本文を準備し、ユーザーの確認後に実行する。

作成ツールはInno Setup 6.7.3。tools/native-ime/Build-NativeInstaller.ps1へ対応ソースを含むTransferZipとISCC.exeのパスを指定する。セットアップは版別フォルダーを既定として旧ZIP版の登録を既存更新処理で更新する。管理画面のアンインストールは登録解除、Windowsのアプリ一覧からのアンインストールは登録解除後にセットアップ配置物を削除する。
