# 管理画面の設定統合と英語文節の区切り変更

2026年10月19日、利用者は入力操作・計算をリンク先へ移動せず管理画面内で設定できること、未公開版の番号を2.0.0に保つこと、意図せず英語と判定された文節もShift+左右矢印で範囲変更できることを要求した。直前の導入版は2.0.1-rc.8。

管理画面内へ入力操作・計算のチェック項目とControl割当を配置する。独立ダイアログとリンクは廃止する。画面内でスクロールして全項目を利用でき、変更は保存操作で反映する。既存の運用ボタンと設定は維持する。表示・登録・更新・インストーラーの番号は、今回の利用者指定により2.0.0へ統一する。本家コアの番号とは区別する。既存の候補番号更新規則に対して今回は利用者の明示指定を優先する。

Nativeで使用するLegacyGoogleConversionの条件が、英語と判定された現在文節と隣の英語文節の境界操作を拒否している。かなの読みを持つ英語文節では、手動のShift+左右操作で読みを日本語として扱い直し、既存の日本語文節と同じ境界変更を使う。境界を動かせない操作では英語表示を変えない。読みを持たない英字や保護されたURL・メールなどを無理にかな化しない。

実装前に英語文節の縮小・拡大、日英境界、操作不能時の無変更を検証する再現試験を追加する。変更後は既存変換、文節候補、モデル、英語直接入力、設定保持、GUI描画、実TSFを検証し、バックアップと標準更新でPCへ適用する。外部公開はしない。

## 実装・検証結果

管理画面を左右2列にし、右側に入力操作・計算のチェック項目とControl割当、保存ボタンを直接配置した。上下スクロールで全項目を操作できる。独立フォームを廃止し、導入済みの旧スクリプトも通常更新のバックアップへ退避して削除した。設定値と保存時の既存・未知項目の保持を確認した。表示・登録・更新・インストーラーの版番号は2.0.0。

修正前は英語文節の縮小と日本語から英語への拡大が失敗した。LegacyGoogleConversionによる拒否を取り除き、かなの読みを持つ文節に既存の境界操作を使えるようにした。Google自動判定で全体が英語表示になっている場合も、Shift+左右で文節操作へ入れる。英語直接入力モードと通常フックのShift+矢印による範囲選択は維持する。移動不能時・読めない英字は表示を変えない。

再現・回帰4/4、全体616/616、Native20/20、Google16/16、Microsoft2/2、標準パッケージ試験が通過。実TSFのcamera入力からShift+Left縮小・Shift+Right拡大・日本語としての確定を確認。上下スクロール状態の画面描画と、主画面の保存ハンドラーによる値の保存・既存項目保持も通過。証跡experimental-build/control-panel-boundary/{red,green,all-managed-final,package-final,inline-save,gui-tests}.logとpanel-{top,bottom}.png。
