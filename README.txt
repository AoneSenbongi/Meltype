Meltype Native Google 2.0.2

本家Meltypeの非公式Forkです。Windows 10／11 x64向けで、Google日本語入力が別途必要です。

今回の更新（2.0.1から）
1. VRChatterのようにかなに読み直せない英語も、Shift+矢印で文節の区切りを動かせるようになりました。
2. Android版と同じく、打った元ローマ字の1音ずつで区切りが移動し、変更後も元ローマ字を保持します。
3. Shift+矢印で明示的に動かした文節区切りだけをMeltype側で覚え、次回同じ元ローマ字に適用します。Google／Mozc側の区切り学習は変更しません。
4. 本家1.6.0の分野辞書（医療・情報・駅名・人名・一般語・法令名）を候補に追加しました。いつもの候補の後ろに並べます。
5. 辞書語が変換エンジンの2次候補の後ろへ押しやられないようにしました。BackSpaceで打ちかけを消したとき、nk＋BackSpace＋a が「んあ」ではなく「な」になるようにも直りました。

2.0.1から引き継いだ機能
- 文章末尾の空の括弧を確定すると内側へ移動し、括弧内の文章を確定すると外側へ移動します。
- Google日本語入力の辞書と学習履歴を使う変換、Google変換での文節編集に対応しています。
- 文脈に応じた候補選択でzenzモデルを使います。AVX2対応CPUが必要で、非対応CPUでは通常変換を使用します。

この配布物は、PC適用済み2.0.2-rc.1に上記の学習・辞書・判定の改善を追加した正式版です。
版番号は2.0.2です。

導入
Meltype-Native-Google-2.0.2-Setup.exeを実行してください。
更新後は入力先のアプリを開き直してください。
