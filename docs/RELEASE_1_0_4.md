# Meltype Native Google 1.0.4

管理画面の操作とエラー表示を改善しました。本家Meltype 1.0.1を基にしたForkです。1.0.3のWindows検索対応、Google日本語入力による日英自動判別・ライブ変換を引き継いでいます。

## 変更点

- エラーを日本語で説明し、詳しい技術情報は別のログへ保存します。
- 起動中は「起動」、停止中は「停止」を押せないようにしました。
- 自動起動をチェックで切り替えられるようにしました。
- 「インストール」と「アンインストール」を並べ、辞書ボタンの青い強調表示を修正しました。
- 管理者処理の起動方法を修正しました。別PCで報告されたインストールエラーの解消は未確認です。

## 導入・更新

Google日本語入力が必要です。ZIPをすべて展開して `Meltype-Settings.exe` を開き、導入済みなら「この版に更新」、未導入なら「インストール」を押してください。辞書・設定・旧版をバックアップしてから更新します。管理者確認が表示される場合があります。

管理画面とバックアップは展開先に残るため、展開先も保持してください。アンインストールには確認画面を設け、Googleの辞書と学習履歴は残します。

## 検証結果と制限

管理画面、操作状態、自動起動設定の同期、更新判定、管理者処理、失敗時の復旧、常駐メニューの試験を通過しました。開発用PCへ管理画面の修正を適用しています。別PCのインストールエラー解消は実機での確認が必要です。

Windows 10検索欄の入力は1.0.3で利用者が確認済みです。Windows 11検索欄、一般のストアアプリ、32ビット・ARM64・署名必須の入力先は未対応または未確認です。Googleとの非公式IPCを使うため、Googleの更新で動作に影響する可能性があります。

入力文字をネットワークへ送る処理は追加していません。コード署名と第三者のセキュリティ監査はありません。権限・保存場所・制限は [SECURITY.md](https://github.com/AoneSenbongi/Meltype/blob/google-native-ime/SECURITY.md)を確認してください。

ZIPにはランタイム・対応ソース・ライセンスを同梱します。個人の辞書・設定・学習履歴・ログは含めません。SHA-256は添付の `.sha256` で確認できます。
