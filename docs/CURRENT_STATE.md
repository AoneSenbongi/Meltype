# 現在の状態

## 有効な目的

Google日本語入力連携を保ちながら、lnkiai氏のIME化Forkを参考にWindows版を改善する。検証した対応範囲を明記して通常Releaseを公開し、本家に新しいIssueで紹介する。Android版は実機確認が不足しているためprereleaseのまま残す。

## 確定済みの実装と決定

PC版はTSFの未確定文字を入力先に表示し、日英判別・ライブ変換・候補選択とGoogleの辞書・学習連携を提供する。管理画面、常駐メニュー、サインイン時の自動起動がある。更新時のハッシュ検証とエラーの連続表示は`1f0f6bb`で修正済み。Googleの本体や辞書は改造・同梱しない。

Windows検索欄で日本語入力できない報告がある。現在はユーザー別COM登録と同じユーザーに限定したパイプを使い、AppContainer対応の権限・配置・登録方式は未実装。検索欄・ストアアプリ・32ビット・ARM64を通常Releaseの対応範囲に含めない。理由と公開条件は`NATIVE_RELEASE.md`を参照する。

## 現在の作業と残作業

秘密入力欄の対象をPIN・プライベート入力に拡張し、最初のパイプ作成で同名サーバーを拒否し、クライアント側でサーバーのユーザーと整合性レベルを確認する変更を実装中。参考実装の出典をREADMEとコードへ記載する。新規Issueとして投稿することをユーザーが明示した。Android版を専用リポジトリへ分ける要求も追加された。

変更後のTSF・Google連携、既存テスト、管理画面と配布物を検証する。SECURITY.mdを実装に合わせて更新し、コミットと配布ZIPを公開する。通常Releaseの状態変更と本家へのIssue投稿は検証後に行う。検証・公開結果に合わせてこの文書を更新する。

## 検証と既知の問題

2026年10月7日、`Test-NativePipe.ps1`で、先に存在する同名パイプの拒否、追加リスナーの作成、正規クライアントとの通信を確認した。追加したTSF試験で秘密入力欄の保護と通信先の確認、Google連携、確定・取消を確認した。既存198件のテスト、管理画面と自動起動のテストも通過した。既存のGoogle連携試験を実行する前に、このPCの旧入力サービスが停止していたため、導入済みの起動スクリプトで再起動し、有効化の成功を確認した。

検索欄での実機動作、AppContainer、32ビットアプリ、署名必須の入力先、Android実機の入力速度と互換性は未検証。通常Releaseという表示は全アプリ対応や第三者の安全性認証を意味しない。
