# Meltype Native Google 2.0.1-rc.9

PC適用済みの2.0.1-rc.9を、そのまま先行版として配布します。

文章末尾の空の括弧を確定すると、その内側へ移動するようにしました。続けて括弧内の文章を確定すると、閉じ括弧の外へ移動して続きを入力できます。

- `文章「」`を確定 → `文章「｜」`
- 括弧内の内容を確定 → `文章「内容」｜`

`｜`は入力位置です。管理画面の「カッコを打ったら中にカーソルを移動」を有効にすると使えます。新しい設定の追加はありません。

通常の括弧内編集は維持し、矢印キー・Home・End・Escやフォーカス変更で自動移動の追跡を解除します。

## 導入

添付のSetup.exeを実行してください。Windows 10／11 x64向けで、Google日本語入力が別途必要です。更新後は入力先のアプリを開き直してください。

文脈に応じた候補選択で使うzenzモデルとCPUランタイムを同梱します。zenzはAVX2対応CPUで利用でき、非対応CPUでは通常変換を使用します。

## 検証と制限

共通・Windowsの自動試験638件が通過。実TSF文書で、文章末尾のペアへの移動、括弧内確定後の退出、連続入力、通常の括弧内編集の維持、Escによる解除を検証しました。

このSetupの別PC導入、32ビットアプリ、すべての入力アプリでの動作は未確認です。
