# 文節操作の割り当て

利用者が2026年10月15日に承認した操作は、左右で対象文節、上下で変換候補、Shift+左右で境界変更である。Shift+左は1文字縮小、Shift+右は1文字拡大とする。Space/TabとShift+Space/Shift+Tabでの候補変更も残す。ライブ表示の文字・境界・モデル採用表記の保持と、英語モードの直接入力維持を継続する。

rc.2専用の上下キー境界変更オプションは不要になるため削除する。候補番号は2.0.1-rc.3。上下が境界を動かさず対象の候補だけを変更し、Shift+左右だけが境界を変更することを単体・実TSF・導入brokerで検証する。標準更新・バックアップでこのPCへ適用し、外部公開しない。
