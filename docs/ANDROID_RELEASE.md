Meltypeを基にした非公式Androidキーボードの試作版です。元作者は雪代／Yukishiro氏です。

QWERTYのローマ字入力で、日英自動判別とOSS版Mozcによるライブ変換を使えます。日英切替ボタンを押すと英語だけの直接入力になり、もう一度押すとMeltypeへ戻ります。切替前の未確定文字は残します。日本語の句読点は全角の「，」「．」です。

対象：Android 8.0以降のarm64端末。x86_64はエミュレーター検証用です。

1. AssetsのMeltype-Android-prototype.apkをAndroidでダウンロードして開きます。
2. APKを開くアプリからのインストールを許可します。
3. Meltypeアプリの「キーボードを有効にする」で有効にします。
4. 「キーボードを選ぶ」でMeltypeを選びます。

入力は端末内で処理します。インターネット権限を要求しません。Gboardのバイナリ・辞書・学習履歴は含めていません。変換にはOSS版MozcとOSS辞書を同梱しています。パスワード欄と数字入力欄は直接入力で、変換・学習を行いません。

日英切替などの入力テストと、AndroidエミュレーターでのJNI接続・日英混在・句読点・入力欄の未確定表示と確定を確認しています。実機での入力速度、各アプリのカーソル・改行・画面回転・長時間入力は未確認です。フリック入力はありません。

署名は試作用です。自動更新はありません。今後、署名が変わる版への更新では再インストールが必要になる場合があります。
