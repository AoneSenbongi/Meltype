# Meltype Native Google 1.1.2-rc.2

Windows独自TSFへ本家の入力機能を移植したローカル候補。Androidは対象外。本家の取り込み基準は9a25e7c、BaseVersionは1.2.1。公開済み1.1.1とPC適用済み1.1.2-rc.1は変更しない。

英語モードでローマ字を検知すると自動モードへ戻る。判定中の英字は即時表示し、直前に入力した文字と位置をTSF内で照合してから未確定範囲へ置き換える。アプリが変換を拒否した場合も英字を保持する。

選択範囲のかな・漢字・ローマ字を変換キーで再変換できる。漢字の読みは本家と同じMicrosoft IMEの逆変換を使う。Enterは確定、Escは元の選択文字の復元。読みを取得できない場合は文字を変更しない。

Tabで変換を開始し、続けてTabで次の候補、Shift+Tabで前の候補を選ぶ。←→で文節を移動する。既存の予測候補・定型文を優先し、空の入力欄ではTabをアプリへ渡す。管理画面にローマ字検知とTab変換の設定を追加した。

2026年10月14日、共通・Windows489/489、品質1337/1337、Native18/18、Google13/13、Microsoft2/2が通過。新機能は隔離データ・学習停止のbrokerと実TSF文書で確認した。予測、定型文、入力モード、候補配置、設定の保持、管理画面の描画、インストーラーの隔離試験も通過した。証跡はexperimental-build/native-upstream-*.logとnative-upstream-panel.png。

通常.NETビルドに既存のnullable警告が3件ある。DLLをdotnetから直接実行する試験形式ではMozcの自己起動試験が失敗するため、通常apphostで全件を確認した。

Windows x64向け。直接入力の自動復帰はTSFの文字位置を取得できる入力欄に対応する。実アプリでの手入力、複数モニター、テーマ切替、32ビットアプリは未確認。Microsoft辞書への学習書き込みは未対応。PC適用とGitHubへの公開は未実施。
