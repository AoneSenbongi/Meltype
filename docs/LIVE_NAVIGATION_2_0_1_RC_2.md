# ライブ表示から文節操作への移行

利用者の指定は、左右で対象文節を移動し、上下で文節の区切りを変更する操作である。上は1文字縮小、下は1文字拡大とする。候補はSpaceまたはTab、前の候補はShift+SpaceまたはShift+Tabで切り替える。F6/F10は必須にしない。Windows Native版だけ上下の役割を変更し、ほかの利用先の既定操作は維持する。

矢印で選択へ入る際は、直前に表示した文字列と文節境界を引き継ぐ。Googleによる再分割や、LLM採用候補の巻き戻しを行わない。表示中の文節と候補をコピーして選択用状態にし、候補の追加取得でも選択済み表記を保持する。上下で境界を変更した場合は、選択文節とその隣だけを再変換する。

2026年10月15日、実導入brokerの隔離private接続でhirumakkunisennka?を入力し、モデル待機後の「昼マックに千か？」が左キーで「昼マックに戦か？」へ戻る現象を確認した。「昼間｜っく」への分割そのものはこの実行では再現していない。別の再現試験は、再変換で境界が変わるconverterと、モデル採用表記を使い、文字列・区切り・対象だけの修正・確定を検証する。

PC適用時の候補番号は2.0.1-rc.2。英語直接入力を保持する設定は継続する。公開・pushは行わない。
