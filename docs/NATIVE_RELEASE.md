# Native Google版の通常Release

通常Releaseの対象はWindows 10／11 x64のデスクトップアプリ向けNative Google版とする。インストール済みGoogle日本語入力との連携、日英判別、ライブ変換、候補選択、辞書と学習履歴の利用を提供する。Android版は実機での確認が足りないため試作版のまま公開する。

次の通常Release候補は1.0.3。2026年10月7日、ユーザーがWindows 10の検索欄で入力できることを確認した。1.0.3には検索向けの保護配置・対応登録・限定通信、Spaceによる候補選択表示の再描画、適用済み更新ボタンの無効化を含める。Windows 11の検索欄と一般のストアアプリは確認していない。公開前にZIP、対応ソース、ハッシュ、説明文を準備し、ユーザーへ提示して承認を受ける。

lnkiai氏のIME化Forkを参考に、PIN・プライベート入力欄の保護と通信先の確認を追加する。元のMeltypeと参考Forkの著作権・ライセンス表記を保ち、参考にした箇所を記載する。

通常Releaseの前に、Google接続、TSF文書の表示・確定・取消、日英混在、句読点、入力モード切替、秘密入力欄の保護、通信先の横取り防止、管理画面の操作と配布物のハッシュを確認する。確認結果はReleaseに記載する。

Windows 10検索対応は、特定パッケージ向け通信、Program Filesへの保護配置、HKLM登録と更新・復旧の変更を含む。検索欄で入力できたことと、すべてのキー操作・候補UIが確認できたことを区別する。32ビットアプリ、ARM64、署名必須のアプリも通常Releaseの対応範囲に含めない。

本家へは新しいIssueでGoogle日本語入力連携版を紹介する。本家への取り込みを要求する内容や先行したことを理由に他のForkを非難する内容にはしない。AIの利用、配布リンク、検証範囲、未対応の入力先を明記する。
