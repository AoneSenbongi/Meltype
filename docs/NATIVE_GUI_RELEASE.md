本家Meltype 1.0.1を取り込んだ非公式Google日本語入力連携版です。元作者は雪代／Yukishiro氏です。

管理画面からインストール、起動・停止、自動起動の切替、更新、単語登録、辞書管理、Googleの設定を操作できます。辞書はGoogle日本語入力の画面を開き、導入先の辞書と学習履歴を使います。入力文字のフォントは元の入力欄のものを維持します。

1. AssetsのWindows x64用ZIPをすべて展開します。Google日本語入力は別途インストールします。
2. `Meltype-Settings.exe`を通常権限で開きます。
3. 新規導入は「インストール」から管理者確認を承認し、「起動」を押します。
4. 導入済みの場合は「この版に更新」を押します。バックアップ後に更新し、再登録せず起動します。

Windowsへのサインイン時に自動起動します。管理画面を閉じるとタスクトレイへ格納します。スタートメニューの「Meltypeの管理画面」からも開けます。単語・辞書・学習履歴は移行用ZIPに含めていません。

既存テスト198件、Googleとの接続、句読点と矢印入力、実際のTSF文書への表示・確定・取消を確認しました。GUIの描画、操作の権限、起動処理、更新前のチェックサム検証も確認しています。Windows 10 x64の現在のPCへ1.0.1を適用しました。32ビットアプリとストアアプリは未検証です。

通常のGoogle日本語入力へ戻す場合は管理画面の「停止してGoogleに戻る」を押します。削除ではGoogleの辞書と学習履歴、バックアップを残します。
