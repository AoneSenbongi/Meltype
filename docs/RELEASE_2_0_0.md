# Meltype Native Google 2.0.0 公開準備

公開先はAoneSenbongi/Meltype、ブランチgoogle-native-ime、予定タグnative-google-2.0.0。タイトルは「Meltype Native Google 2.0.0（本家1.3.0対応）」。EXEとSHA-256ファイルを準備し、公開内容の確認後にpush・タグ作成・Release公開を行う。現時点では未公開。

## Release本文案

本家Meltype 1.3.0の共通変換処理・判定・辞書を取り込んだ、Windows x64向けの非公式Native IMEです。Google日本語入力／Microsoft IMEの切り替えに対応します。

- 入力操作・計算の設定を管理画面に直接配置しました。計算式をSpaceで変換すると結果を候補から選べます。
- ブランドアイコンを本家1.3.0の「雪の結晶＋M」に更新しました。IME登録、管理画面・トレイ、管理ランチャー、インストーラーへ反映しています。
- 英語と誤判定された文節も、Shift＋左右で範囲を変更できます。変更後の文節でもGoogleの候補を選べます。
- 括弧対の確定後に内側へ移動する設定を修正しました。アプリが確定通知で選択位置を戻す場合にも、通知後に括弧内を指定します。
- 候補欄のサイズ・位置の更新、数字付きの短い単位の変換、Shift＋Spaceの全角空白など、先行適用版の修正を含みます。

管理画面の版番号は2.0.0、本家の基準版番号は1.3.0です。既存の句読点・辞書・設定を保持します。

### 検証

共通・Windows回帰637/637が通過。Native20/20、Google16/16、Microsoft2/2、実Windows TSF文書の変換・確定・取消・文節操作・括弧内移動、設定保存・保護欄・学習停止・定型文の試験を実施しました。括弧内移動は、アプリが確定通知で選択位置を戻す再現試験で修正前の失敗と修正後の成功を確認しました。

### 必要なものと制限

- Windows 10／11 x64。Google変換にはGoogle日本語入力を別途インストールしてください。
- 更新後は入力アプリを再起動してください。開いたままのアプリは旧Native DLLを使い続けます。
- ローカルzenzモデル本体と、この開発用PC固有のモデル設定は同梱しません。配布版はGoogle／Microsoftによる変換で動作します。
- 子音略入力・文脈別の日英学習など、本家の追加機能すべてを独自Native設定へ接続したものではありません。
- Codexと管理画面での今回の括弧不具合の解消は、PC適用後の利用者確認待ちです。32ビットアプリ・複数モニターの実操作は未確認です。

個人の辞書・入力履歴は配布しません。対応ソースとライセンスはインストーラーに同梱します。
