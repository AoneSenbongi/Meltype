# Meltype Native Google 1.0.8-rc.2

本家Meltype 1.2.1の共通コア・辞書・予測を取り込んだWindows向け候補です。Google日本語入力との連携、独自の句読点設定、学習停止、検索欄対応と管理画面を維持します。

自動変換とSpace変換は従来の判定・候補順を保持します。Tabは予測候補の選択に使います。本家の定型文管理画面、選択範囲再変換、Tabでの文節変換は独自TSF版へ追加していません。

共通400件、Windowsを含む422件、品質1292件の試験が通過しました。GoogleからTSF文書への変換・予測・確定・取消、検索AppContainerの通信と相手確認、版番号、管理画面、更新と失敗時の復旧を検証済みです。Googleを使う試験では学習を無効にしました。

このPCへの適用と実入力欄の確認は未実施です。Android版は変更していません。外部公開は行っていません。
