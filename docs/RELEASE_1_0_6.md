# Meltype Native Google 1.0.6

Google日本語入力による従来の変換を維持し、本家Meltype 1.1.0の予測候補を追加しました。

## 変更点

- 続きの予測候補を追加しました。Tab／Shift+Tabで選び、Enterで確定、Escで選択を解除します。Spaceは従来の変換に使います。
- 自動変換・Space変換は従来の判定とGoogle日本語入力を使います。本家1.1.0の同梱語句は予測にのみ使います。Googleの辞書・学習履歴は初期化しません。
- 日本語の文中でもzh／zj／zk／zlをSpaceなしで←／↓／↑／→へ変換します。
- 先頭の[を未確定入力に含め、日本語が続けば「、英語なら[にします。閉じ括弧も対応する幅に揃えます。
- 管理画面・登録状態・インストーラーの表示番号を1.0.6へ統一しました。
- 日本語Windowsで管理者確認が取り消された場合、その原因をセットアップのエラー画面で案内するようにしました。

句読点の選択・学習停止、起動・停止ボタンの状態判定、通信枠32など、1.0.5の機能を引き継ぎます。

## 導入・更新

Windows 10／11 x64とGoogle日本語入力のインストールが必要です。`Meltype-Native-Google-1.0.6-Setup.exe`を通常のダブルクリックで開き、必要な管理者確認を承認してください。更新時は辞書・設定・旧版をバックアップします。更新後は入力するアプリを完全に終了して開き直してください。

デスクトップショートカットはセットアップで選べます。Windowsのアプリ一覧から削除でき、Googleの辞書・学習履歴とバックアップは残ります。旧ZIP版から更新した場合は旧導入フォルダーも保持してください。

## 検証・制限・セキュリティ

共通・Windowsテスト294件、Google変換からTSF入力欄への反映、予測候補の選択・確定・取消、先頭の括弧、表示番号の一致、管理画面の状態判定、更新と失敗時の復旧、句読点・学習停止の試験を通過しました。このPCで同じ変換・予測の実装を適用し、稼働中サービスの応答と管理画面のボタン状態、更新前後のGoogleの辞書・設定・履歴の一致を確認しています。

新規導入・削除・別PC・Windows 11検索欄の動作と、突発停止の長期的な改善は未確認です。選択範囲の再変換、32ビット・ARM64には対応していません。

予測用の確定語句はPC内のMeltypeフォルダーへ保存します。学習停止中は履歴へ追加しません。入力内容をネットワークへ送る処理は追加していません。Googleとの非公式IPCを使うため、Googleの更新で影響する場合があります。コード署名と第三者のセキュリティ監査はありません。保存場所と権限は[SECURITY.md](https://github.com/AoneSenbongi/Meltype/blob/google-native-ime/SECURITY.md)を確認してください。

ランタイム・対応ソース・ライセンスを同梱し、個人の辞書・設定・学習履歴・ログは含めません。SHA-256は添付の`.sha256`で確認できます。
