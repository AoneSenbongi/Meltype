# 文脈別の区切り学習の比較仕様

2026年10月15日。手動で修正した区切りを、文脈を考慮して再利用する方式を評価する。製品への接続・PCへの適用は比較後に行う。

## 比較

同じ読みの異なる区切り・表記を教師が用意し、文脈履歴、zenz、併用を比較する。学習文と評価文は分離する。候補の順序を反転して再実行する。候補先頭固定・最後の修正固定は対照用の模擬方式であり、Googleの実測精度ではない。

12組、学習48文、評価120文に10条件を加えた1,200件を実行する。前文脈、後文脈、丁寧表現、質問、長い前後文脈、英数・別話題の隣接を含む。追加で反対の意味への言及、話題転換、左右の文脈の競合を調べる。条件を変えた件数と独立した意味例数を区別する。文脈は製品と同じ左256文字・右128文字に制限する。

## 独立した履歴試作

ContextBoundaryMemoryは製品へ接続しない比較用の実装。かなの読み2〜64文字、正の文節長の合計一致、最大32文節を受け付ける。文脈は左256文字・右128文字、最大1,024記録に制限する。空文脈は記録しない。同じ読み・同じ文脈への明示修正は最新を保持し、他の文脈は別に保存する。

文字bigramと漢字の集合を使ったcosine類似度を比較し、最高値0.45以上、次点との差0.12以上の場合だけ採用する。閾値は比較前に固定し、今回の評価結果に合わせて調整しない。返す配列は複製する。破損・不正な保存内容は採用せず、最大4MBまで読む。保存は同じディレクトリーの一時ファイルから置換する。保存失敗時の動作も検証する。

## 未接続部分

同一表記で区切りだけ異なる場合、自然文を返す現行zenz方式では区別できない。保存試作で区別できるか検証する。private欄、学習停止、取消し、非同期結果の失効は既存機能の回帰と新しい区切り学習への接続試験を区別する。未接続の試作だけでこれらの製品動作が検証済みとはしない。
