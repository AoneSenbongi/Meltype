# ローカルzenzによる未変換入力の再評価

2026年10月20日の利用者の依頼に基づく。WindowsとAndroidで小型zenzをローカル実行し、誤字の反復によって英語扱いになった入力も確定前に再評価する。Androidの実装・実機検証は実機が接続された別PCのチャットへ依頼済み。

## Windowsの動作

1. 自動モードで未変換の英字が残る入力について、元の打鍵から既存のローマ字誤字補正で読みを作る。辞書未登録だけでは誤字としない。
2. 正常な英単語・固有名詞・ユーザー辞書・明示的な英語選択、URL・コード・数字を保護する。誤って蓄積された非明示の言語学習は単語の正しさの根拠にしない。
3. 元の表示と、修正した読みを既存エンジンで変換した候補に限定してzenzで評価する。元の表示も必ず候補に含める。
4. 入力中は非同期で再評価する。Enter/通常Space時に評価が未完了なら上限内で確定を保留する。失敗・時間切れでは元の表示を確定する。表示どおり確定する設定は優先する。
5. 新しい入力・削除・取消・入力欄変更・手動候補選択後に古い推論結果を適用しない。元の打鍵を編集用に保持する。自動補正結果を言語選択や語句の好みとして学習しない。

未変換英字のない同音異義語の選択は既存の文節評価を使う。今回の補正対象は既存補正器で読みを作れるローマ字誤字に限る。未知の略語や複数の誤りで候補を作れない入力を自由生成で書き換えない。

## 検証

英語として学習された誤字、正常英語、固有名詞、URL、数字、手動モード、Enter/Space、保留中の続き入力・削除・Esc、遅延応答、時間切れ、学習への逆流をテストする。小型zenz実モデルでも候補制約と採否を確認する。画面操作は実施しない。
