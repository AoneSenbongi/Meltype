# 本家1.2.1の取り込み

Windows Native Google版へ本家v1.2.1を取り込む。独自候補番号は1.0.8-rc.2とし、本家コア1.2.1と区別する。Android版は変更せず、共通コアと辞書の変更を調査して対応方針を提示する。

Google日本語入力との接続、独自TSF、検索向け通信制限、管理画面、句読点設定、学習停止を維持する。通常変換の従来の判定・分節・候補順を保持し、予測へ本家コアを使う既存方針を維持する。本家のTSFと既定IME変更を独自TSFへそのまま移さない。

共通・Windows回帰試験、GoogleとTSFの変換・予測・取消、学習停止、検索通信、管理機能と版番号を検証する。配布物をローカルで準備し、導入と公開は結果を分けて記録する。GitHubへのpush・Releaseは具体的な内容の提示後に承認を受ける。

2026年10月11日、取り込み前の作業ツリーはクリーン。本家タグ47ace14を取得し、README、共通コア、共通試験、CompositionServiceの競合を解消した。括弧追跡と従来の候補順を保持し、本家のバッククォート修正を追加した。独自の学習停止と本家の学習設定の両方を確認してから履歴へ保存する。

共通400/400、Windowsを含む422/422、品質1292/1292が通過。Googleから実TSF文書の変換28更新と予測16更新、確定・取消、Tab選択・Esc解除、先頭括弧が通過した。学習を無効にして試験した。検索AppContainerから実DLL・broker・Googleへの変換と、通信相手の確認・別パッケージ拒否・同名占有拒否も通過した。管理画面、版番号、句読点設定、通信枠32、更新判定、インストーラー、更新失敗時の復旧を検証した。

選択範囲再変換は独自TSFでは未対応。定型文管理・展開は後続の1.1.0-rc.3で実装した。詳細はdocs/NATIVE_SNIPPETS.mdを参照する。Tabは既存の予測選択に使い、本家のTab変換を有効化しない。Nativeパッケージは構築済み。稼働中IMEへの適用、ユーザーの実入力欄での確認、外部公開は未実施。

## Android版の判断

共通コアと辞書の修正は取り込む価値がある。ファイル拡張子・固有名詞・日英混在の誤判定を対象とし、WindowsのTSF、設定画面、キー操作の変更は移植対象から外す。Androidは独自のMozc接続、部分確定、句読点、辞書、学習用の収集処理を持つため、別の候補で既存試験と端末入力を確認してから更新する。

Androidの作業ツリーには未コミットの変更があり、状態資料は2026年10月10日の端末入力記録の取得を確認している。今回Androidのソース、APK、端末、学習データは変更していない。全機能の同時追従より、共通部分の修正を選んで取り込むことを勧める。
