# 2.0.2-rc.1 文節移動の修正（PC適用候補）

## 依頼と対象

Windows IMEで`VRChatter`を入力すると`VRCはってr`と表示される。Android版と同じく、Shift+→で文節の区切りを動かして`VRChatter`に戻せるようにする。このPCに適用済みの2.0.1系（本家コア1.3.0）が対象。公開済みの2.0.1正式版と同じ番号で内容だけ差し替えないため、版番号は2.0.2-rc.1。

## 変更

- `CompositionController.Resize`: かなに読み直せない英語の文節も、打った元ローマ字の1音単位で区切りを動かす。かなに読み直せる英語は従来どおり日本語の文節として扱う。
- 文節を伸ばすとき、日本語の文節の次に読み直せない英語があれば元ローマ字ごと英語の1文節にまとめる。縮めるときは、外れた1音と元ローマ字を次の文節へ渡す。
- `CompositionText.FinalUnits()`と`ReconvertKeepingRaw`を追加し、区切り変更後も元ローマ字を保持する。
- 最後の文節、および選んだ英語の文節の次にかなに読めない英語がある場合は、何も変更しない従来の挙動を維持する。

## 検証

- Shift+矢印の回帰5件すべて通過。新規試験`Clauses_ShiftArrowResizesAcrossUnreadableEnglish_LegacyGoogle`は、修正を戻すと`vrc|はって|r`のまま失敗し、修正後は`vrchat|ter`まで寄せて確定できる。
- Meltype.Core.Tests 598/598、Meltype.Tests 638/639。失敗1件は実行シェルでクリップボード操作が使えないことによる既存試験で、今回の変更とは無関係。
- Test-NativeVersion.ps1通過（管理画面・登録・インストーラー・更新メッセージ・オンライン更新）。
- PC適用: 2.0.1-rc.9から2.0.2-rc.1へ更新。変更した配置ファイルは`Meltype.Core.dll`のみで、残り6ファイルは既存と同一。配置7/7、スクリプト7/7、設定3/3のハッシュ一致。brokerは新登録先で稼働。
