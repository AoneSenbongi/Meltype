# Meltype Native Google 1.0.5

句読点の選択・学習停止を追加し、起動ボタンの状態判定と通信枠が満杯になったときの処理を修正しました。本家Meltype 1.0.4を基にした非公式Forkです。

## 変更点

- 本家v1.0.4の拡張ローマ字表記と日英・かなキーの判定改善を取り込みました。Qtアプリ向け修正は常駐版のソースに含みますが、Native Google版は引き続きTSFで入力します。
- 読点「、／，／,」と句点「。／．／.」を個別に選べます。英語入力の句読点は半角のピリオド・カンマのままです。
- 学習を停止・再開できます。既存の辞書・履歴は残し、通常のGoogle日本語入力の学習設定は変更しません。
- 起動中は「起動」、停止中は「停止」を押せないようにしました。状態確認に失敗した場合も操作を無効にします。
- 通信枠を32へ増やし、枠が満杯のときは空きを待つようにしました。接続先の確認と通信権限の制限は維持しています。

## 導入・更新

Windows 10／11 x64が対象です。Google日本語入力のインストールが必要です。`Meltype-Native-Google-1.0.5-Setup.exe`を通常のダブルクリックで開き、必要な管理者確認を承認してください。更新時は辞書・設定と旧版をバックアップします。更新後は入力するアプリを開き直してください。

デスクトップショートカットはセットアップで選べます。削除はWindowsのアプリ一覧から行えます。Googleの辞書・学習履歴とバックアップは残ります。旧ZIP版から更新した場合は、旧導入フォルダーも保持してください。

## 検証・制限・セキュリティ

共通・Windowsテスト218件と、句読点、学習停止、起動・停止、更新判定、候補表示、通信権限の試験を通過しました。本家1.0.4を取り込む前の版では、開発用PCへの更新と管理画面のボタン状態を確認済みです。本家1.0.4を取り込んだ配布物の実機更新は未確認です。

新規導入・削除・別PCでの動作、Windows 11の検索欄は未確認です。報告された突発停止の解消は長期利用での確認が必要です。選択範囲の再変換、32ビット・ARM64には対応していません。

入力文字をネットワークへ送る処理は追加していません。Googleとの非公式IPCを使うため、Googleの更新で動作に影響する場合があります。コード署名と第三者のセキュリティ監査はありません。権限・保存場所・制限は[SECURITY.md](https://github.com/AoneSenbongi/Meltype/blob/google-native-ime/SECURITY.md)に記載しています。

ランタイム・対応ソース・ライセンスを同梱し、個人の辞書・設定・学習履歴・ログは含めません。SHA-256は添付の`.sha256`で確認できます。
