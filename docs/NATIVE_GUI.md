# PC版の管理画面

本家Meltype 1.0.3を取り込み、Google日本語入力を使うNative版に管理画面を追加する。入力は元のテキストボックスへ表示する。辞書・学習履歴は導入先のGoogle日本語入力のものを使う。

`Meltype-Settings.exe`を通常権限で開く。画面にはインストール状態と入力サービスの状態を表示する。起動・停止・自動起動の設定は管理者権限を要求しない。初回のインストールと削除ではWindowsの管理者確認を表示する。

配布ランタイムで更新ファイルのSHA-256を検証できるよう、検証処理はPowerShellの追加コマンドに依存しない。処理の完了結果はエラー画面を表示する前に消費する。エラー画面を開いている間にタイマーが再実行されても、同じ結果を繰り返し表示しない。

1.0.3は、DLL・変換サービスの配布ファイルをProgram Filesの保護された版別フォルダーへ配置する。配布ファイルの変更か登録方式の移行時に管理者確認を出し、HKLMのCOM登録へ切り替える。管理画面だけの更新では配布ファイルを交換しない。使用中のDLLを上書きしない。失敗した場合は前の登録先と状態へ戻す。更新後も古いDLLを使っているアプリは開き直す。1.0.2の配置方式とは異なる。Windows 10の検索欄で入力できることは開発用PCで確認済み。Windows 11の検索欄は未確認。

1. 未導入の場合は「インストール」を押す。登録に成功したら「起動」を押す。
2. 導入済みの場合は、新しい配布ZIPを展開して管理画面を開き、「この版に更新」を押す。Googleの設定と履歴、交換するファイルをバックアップしてから入力サービスを止め、更新して起動する。必要な再登録は内部で行う。失敗時は旧登録と旧設定へ戻す。
3. 「単語登録」「辞書を管理」「Googleの設定」はGoogle日本語入力の画面を開く。別の辞書を作らない。
4. 自動起動の有効・無効を管理画面から切り替える。サインイン後は入力サービスとトレイの管理画面を非表示で起動する。

画面を閉じるとトレイへ格納する。Meltypeの常駐アイコンを右クリックすると「停止してGoogleに戻る」「単語登録」「辞書管理」を直接操作できる。単語登録と辞書管理ではGoogle日本語入力の画面を開く。Windows標準の「あ／A」アイコンとは別のメニューになる。「管理画面を終了」は管理画面だけを終了する。

本家1.0.3のWindows常駐画面、Mac、Linux向けの修正もソースへ取り込む。Native版で使うのは共通の日英判定・辞書・ログ処理。英単語の前後にスペースを入れる設定は本家と同じく初期状態では無効にする。

## 更新内容が同じ場合

配布ペイロード、管理画面のスクリプトとランチャーが導入済みの内容と一致する場合、「この版は適用済み」と表示し更新ボタンを無効にする。番号が同じでも修正内容が異なる場合は更新できる。更新スクリプトを直接実行しても、同一内容ならバックアップや入力サービスの停止を行わず終了する。変更した配布ペイロードのハッシュが不正な場合は更新を許可しない。

別のフォルダーから更新した場合は、導入先の配布元ペイロードも適用した版へ同期する。導入済みのショートカットから開き直しても、古い配布ファイルを再適用する表示にならない。

1.0.4のセットアップ版はEXEから導入する。管理画面のショートカットをデスクトップとスタートメニューへ追加し、Windowsのアプリ一覧からセットアップの削除を行える。管理画面のアンインストールはIME登録の解除を行い、管理画面とバックアップは残す。
