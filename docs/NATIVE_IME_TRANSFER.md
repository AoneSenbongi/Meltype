# 自分のPCへの導入

対象はWindows 10／11の64ビット版。ARM版と32ビット版にはこのZIPを使わない。Google日本語入力は別途インストールする。開発環境やCodexは不要。

入力データの保存、権限、署名、報告先は[このForkのセキュリティ説明](https://github.com/AoneSenbongi/Meltype/blob/google-native-ime/SECURITY.md)を確認してください。新しい配布ZIPには`SECURITY.md`も同梱しています。

1. Google日本語入力をインストールし、一度日本語を入力して動作を確認する。
2. ZIPを`C:\MeltypeNative`など、移動しない場所へすべて展開する。ZIP内から直接起動しない。ダウンロードしたZIPに「ブロックの解除」がある場合は、展開前にプロパティで解除する。
3. `Meltype-Settings.exe`を開き、「インストール」を押す。普段使うWindowsアカウントで管理者確認を承認する。Googleの設定と学習データをバックアップしてからIMEを登録する。
4. 「起動」を押す。スタートメニューにも「Meltypeの管理画面」を追加する。

本家Meltype 1.0.1を取り込んだ版。導入済みの場合は、新しいZIPを別の場所へ展開して`Meltype-Settings.exe`を開き、「この版に更新」を押す。Googleの設定・履歴と更新前のファイルをバックアップしてから更新する。DLLが変わる更新では管理者確認が表示され、登録先も更新する。単語登録、辞書管理、Googleの設定、自動起動の切替も管理画面から操作できる。画面を閉じるとトレイに格納する。

日本語の句読点は全角の「，」「．」。ローマ字入力の区切りで`zh → ←`、`zj → ↓`、`zk → ↑`、`zl → →`を使える。Google本体でも同じ句読点を使う場合は、Google日本語入力のプロパティで句読点を「，．」に設定する。Googleへ新しい履歴を追加する場合は「学習する」を選ぶ。

インストール時にWindowsへのサインイン後の自動起動を設定する。起動時のコンソールは非表示。自動起動の有効・無効は管理画面から切り替える。設定変更前の自動起動情報は`backups`に保存する。通常のGoogle日本語入力へ戻す場合は「停止してGoogleに戻る」を押す。次回のサインインでもGoogleを使う場合は、自動起動も無効にする。削除は管理画面の「削除」から行い、バックアップは残る。登録後にフォルダーを移動する場合は、先に登録を削除する。

Meltypeの常駐アイコンを右クリックすると「停止してGoogleに戻る」「単語登録」「辞書管理」を直接操作できる。Windows標準の「あ／A」のメニューは変更していない。

現在の1.0.3用ZIPは、句読点・疑問符でライブ変換がかなへ戻る問題と起動待ち時間の修正を含む。旧版からは管理画面の「この版に更新」で適用でき、個別の修正ZIPや辞書の移行は不要。

個人の辞書・学習履歴・設定はこのZIPに入っていない。導入先のPCにあるGoogleの辞書と履歴を使う。実際のアプリでのフォント・改行・候補配置は導入後に確認する。32ビットアプリとストアアプリは未検証。

1.0.3ではDLLなどの変換ファイルをProgram Filesの保護された版別フォルダーへ配置する。管理者確認が必要。管理画面・設定・バックアップは展開先に残るため、展開先も保持する。旧版からの更新でも辞書・学習履歴を維持する。更新後は入力アプリを開き直す。Windows検索欄へ反映されない場合はPCを再起動する。Windows 10の検索欄で入力できることは開発用PCで確認済み。Windows 11の検索欄と一般のストアアプリは未確認。
