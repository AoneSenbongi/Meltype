# Meltype Native Google 1.0.4

管理画面の操作とエラー表示を改善しました。本家Meltype 1.0.3を基にしたForkです。1.0.3のWindows検索対応、Google日本語入力による日英自動判別・ライブ変換を引き継いでいます。

## 変更点

- EXEインストーラーとデスクトップショートカットを追加しました。Windowsのアプリ一覧から削除できます。

- 本家v1.0.3を取り込み、日英・かな入力の判定、ciのローマ字変換と候補辞書を更新しました。
- エラーを日本語で説明し、詳しい技術情報は別のログへ保存します。
- 起動中は「起動」、停止中は「停止」を押せないようにしました。
- 自動起動をチェックで切り替えられるようにしました。
- 「インストール」と「アンインストール」を並べ、辞書ボタンの青い強調表示を修正しました。
- 管理者処理の起動方法を修正しました。別PCで報告されたインストールエラーの解消は未確認です。

## 導入・更新

Google日本語入力が必要です。`Meltype-Native-Google-1.0.4-Setup.exe` を通常のダブルクリックで開き、保存先とショートカットを確認して進めてください。新規導入または更新後にIMEを起動します。必要な管理者確認を承認してください。旧ZIP版からも更新でき、辞書・設定・旧版をバックアップします。

管理画面とバックアップは導入先に残ります。旧ZIP版からの更新では旧導入先も保持してください。アンインストールには確認画面を設け、Googleの辞書と学習履歴は残します。

## 検証結果と制限

共通・Windowsテスト208件、GoogleからTSF入力欄への変換、候補表示、Windows検索向け通信、管理画面と更新・復旧の試験を通過しました。開発用PCへ管理画面の修正を適用しています。セットアップの導入・更新・取消・削除失敗とショートカットの試験を実施しています。インストーラーによる実際の登録・削除はまだ確認していません。別PCのインストールエラー解消は実機での確認が必要です。

本家の選択範囲再変換はNative IMEでは未対応です。

Windows 10検索欄の入力は1.0.3で利用者が確認済みです。Windows 11検索欄、一般のストアアプリ、32ビット・ARM64・署名必須の入力先は未対応または未確認です。Googleとの非公式IPCを使うため、Googleの更新で動作に影響する可能性があります。

入力文字をネットワークへ送る処理は追加していません。コード署名と第三者のセキュリティ監査はありません。権限・保存場所・制限は [SECURITY.md](https://github.com/AoneSenbongi/Meltype/blob/google-native-ime/SECURITY.md)を確認してください。

インストーラーにはランタイム・対応ソース・ライセンスを同梱します。個人の辞書・設定・学習履歴・ログは含めません。SHA-256は添付の `.sha256` で確認できます。
