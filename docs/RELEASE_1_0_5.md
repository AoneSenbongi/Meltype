# Meltype Native Google 1.0.5

句読点の選択と学習停止を追加し、通信枠が満杯になると入力サービスが終了する問題を修正しました。本家Meltype 1.0.3を基にした非公式Forkです。

## 変更点

- 管理画面で読点「、／，／,」と句点「。／．／.」を個別に選べます。英語入力は半角のままです。
- 「学習を停止／学習を再開」でMeltype経由の新しい学習を切り替えられます。既存の辞書・履歴は残ります。通常のGoogle日本語入力の学習設定は変更しません。
- 通信枠を32へ増やしました。満杯のときは空きを待ち、入力サービスを終了しません。接続先の確認と通信権限の制限は維持しています。

## 導入・更新

Google日本語入力が必要です。`Meltype-Native-Google-1.0.5-Setup.exe`を通常のダブルクリックで開き、必要な管理者確認を承認してください。旧版からの更新では辞書・設定と旧版をバックアップします。更新後は入力するアプリを開き直してください。

デスクトップショートカットはセットアップで選べます。削除はWindowsのアプリ一覧から行えます。Googleの辞書・学習履歴とバックアップは残ります。旧ZIP版の導入先も保持してください。

## 検証と制限

共通・Windowsテスト212件を通過しました。句読点9組合せと学習停止・再開、管理画面の操作状態、更新判定、候補の再描画、通信枠32・満杯時の待機・取消、インストール処理の分岐を検証しました。隔離したAppContainerから実Googleを使うライブ変換・候補選択・確定と、不正な接続先の拒否も確認しました。

報告された突発停止との因果と長期利用での改善は未確認です。別PCでのインストール、Windows 11の検索欄、本家の選択範囲再変換は未確認または未対応です。32ビット・ARM64には対応していません。

入力文字をネットワークへ送る処理は追加していません。Googleとの非公式IPCを使うため、Googleの更新で動作に影響する場合があります。コード署名と第三者のセキュリティ監査はありません。[SECURITY.md](https://github.com/AoneSenbongi/Meltype/blob/google-native-ime/SECURITY.md)に権限・保存場所・制限を記載しています。

ランタイム・対応ソース・ライセンスを同梱し、個人の辞書・設定・学習履歴・ログは含めません。SHA-256は添付の`.sha256`で確認できます。
