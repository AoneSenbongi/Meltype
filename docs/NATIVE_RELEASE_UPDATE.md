# 管理画面からの更新

先行版1.0.7-rc.1では、更新成功後に旧管理画面を終了し、新しい版の管理画面を開く。IMEの更新に失敗した場合は旧版と管理画面を保持する。PC全体は再起動しない。同じ利用者・同じWindowsセッションで、既存導入先、新版、または更新前のスタートメニューの管理画面ショートカットが指すスクリプトを実行しているプロセスのみを対象にする。IMEの管理先と管理画面の保存先が異なる場合も旧画面を置き換える。入力サービスやほかのPowerShellは終了しない。

管理画面の「最新版を確認」でAoneSenbongi/Meltypeの最新の通常Releaseを取得する。取得は別プロセスで行い、画面を止めない。新しい版があれば版番号を表示し、利用者が更新を選んだ時だけインストーラーを取得して実行する。ダウングレード、Android版、プレリリースは対象にしない。無人の自動インストールは行わない。

取得元はGitHubの公開APIと、このリポジトリのRelease添付に限定する。版番号・ファイル名・添付サイズ・APIのSHA-256を確認し、SHA-256不一致、添付不足、通信失敗では実行しない。取得先は管理画面のフォルダー内のupdatesとし、Eドライブの導入先ではEへ保存する。セットアップの保存先も同じ親フォルダーの新版番号へ揃える。既存のバックアップ・管理者確認・失敗時の復旧を使う。管理者確認は省略しない。

GitHubへ入力内容・辞書・学習履歴を送らない。ログインやGitHubトークンは不要。GitHubへ通信するのは最新版確認と更新取得時だけで、キーボードの入力処理には通信を追加しない。署名のないEXEであり、SHA-256は第三者による安全性保証ではない。
