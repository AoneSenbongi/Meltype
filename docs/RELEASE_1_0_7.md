# Meltype Native Google 1.0.7

Windows 11検索欄の変換修正と、管理画面からの更新機能を追加しました。

## 変更点

- Windows 11の検索アプリに合わせて通信先の識別子を選び、検索欄で変換できない問題を修正しました。Windows 10の対応も維持します。
- 更新成功後に旧管理画面を終了し、新版を自動で開きます。
- 「最新版を確認」からGitHubの通常Releaseを確認し、更新を選ぶとダウンロード・SHA-256照合・バックアップ・セットアップを実行します。管理者確認は必要です。
- 管理画面・登録状態・インストーラーの表示番号を1.0.7へ統一しました。

Google日本語入力による変換・学習履歴と、1.0.6の予測候補・句読点設定を引き継ぎます。

## 導入・更新

Windows 10／11 x64とGoogle日本語入力のインストールが必要です。`Meltype-Native-Google-1.0.7-Setup.exe`を通常のダブルクリックで開いてください。更新前に辞書・設定・旧版をバックアップします。管理画面は自動で開き直しますが、入力に使うアプリは完全に終了して開き直してください。

1.0.6以前からの更新は今回のインストーラーをダウンロードしてください。1.0.7以降は管理画面の「最新版を確認」を使えます。無人での自動インストールは行いません。

## 検証・制限・セキュリティ

Google変換・TSF入力・予測、Windows 10／11の検索パッケージ選択、検索用AppContainerの通信と接続先拒否、管理画面の状態、更新・自動再起動・失敗時の復旧、表示番号の試験が通過しました。Windows 11の検索欄はThinkPadで同じ修正を含む候補版による変換を利用者が確認しています。全キー操作と正式版のWin11実機適用は未確認です。

選択範囲の再変換、32ビット・ARM64には対応していません。一般のストアアプリと突発停止の長期的な改善は未確認です。

更新確認ではGitHubの公開APIとこのForkのRelease添付へ通信し、入力内容・辞書・学習履歴・GitHub認証情報は送りません。検索アプリへの通信許可を限定し、双方の接続先確認を維持します。Googleとの非公式IPCを使うため、Googleの更新で影響する場合があります。コード署名と第三者のセキュリティ監査はありません。詳細は[SECURITY.md](https://github.com/AoneSenbongi/Meltype/blob/google-native-ime/SECURITY.md)を参照してください。

ランタイム・対応ソース・ライセンスを同梱し、個人の辞書・設定・学習履歴・ログは含めません。SHA-256は添付の`.sha256`で確認できます。
