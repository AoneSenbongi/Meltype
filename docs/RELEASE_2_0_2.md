# Meltype Native Google 2.0.2

PC適用済み2.0.2-rc.1と同じIME本体を、2.0.2正式版として配布します。本家コアは1.3.0のままです。

`VRChatter`のようにかなに読み直せない英語の文節も、Android版と同じくShift+矢印で区切りを動かせるようになりました。打った元ローマ字の1音ずつで区切りが移動し、区切りを変えた後も元ローマ字を保持します。かなに読み直せる英語は従来どおり日本語の文節として扱います。最後の文節や、選んだ英語の次にかなに読めない英語が続く場合は、従来どおり何も変更しません。

## 導入

添付のSetup.exeを実行してください。Windows 10／11 x64向けで、Google日本語入力が別途必要です。更新後は入力先のアプリを開き直してください。

文脈に応じた候補選択で使うzenzモデルとCPUランタイムを同梱します。zenzはAVX2対応CPUで利用でき、非対応CPUでは通常変換を使用します。
